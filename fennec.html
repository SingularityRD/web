Questions about Fennec

What is Fennec?

Fennec is Singularity’s code security scanner. In seconds, it checks code in 14 languages for vulnerabilities, leaked secrets, risky dependencies and encryption that quantum computers could break. It is named after the fennec fox: small, fast, with ears that hear what others miss.

Who is Fennec for?

Fennec is for any team that writes software. That includes software and SaaS companies, banks and fintech, defense and public sector, telecom and e-commerce, software agencies, and teams that write code with AI assistants.

How is Fennec different from other code scanners?

When a scan takes minutes, developers switch it off. Fennec finishes in seconds, fast enough to run before every change is committed. It covers code, secrets, dependencies, configuration and quantum readiness in one tool, and shows only the new problems each change adds.

Can Fennec run on-premises or air-gapped?

Yes. Fennec runs on your own machines and your code never leaves. It can be installed air-gapped, on a network with no internet connection. Code, secret and encryption scans run fully offline; dependency checks look up a public database of known vulnerabilities.

How do developers stay in control of Fennec?

Fennec reports what it finds and developers decide. Automatic fixes cover supported issues only, and a developer applies them. A finding can be accepted with a note in the code, which reviewers see in the pull request.
