04 AIDR · AI agent detection & response

Others read the prompt. AIDR watches the kernel.

AI agents don’t just talk. They spawn processes, open files and call the network. Prompt filters and AI gateways only see the conversation. AIDR runs at the kernel level — it sees what an agent actually does, and stops it before it happens.

Layer an agent acts on Prompt filters AI gateways AIDR
Prompts & outputswhat the agent says
Model & API callswhich model, which data
Tools & MCP serverswhat it is allowed to touch
Processes & fileswhat it actually runs
Network & syscallswhere data actually goes

  1. See

    Every agent — from prompt to syscall.

    A live map of agents, models, MCP servers and every process they spawn, including the shadow ones nobody registered.

  2. Stop

    In the kernel, before execution.

    Prompt injection, tool abuse, poisoned packages and exfiltration are cut off at the system call. Safe actions never slow down.

  3. Prove

    A replayable record of every decision.

    What the agent saw, what it ran, what AIDR did — sealed into the same evidence chain as your SOC.

The only layer an agent can’t talk its way past.

Frequently asked questions

What makes AIDR different from a prompt firewall or AI gateway?

Depth. Prompt firewalls and gateways see the conversation. AIDR also runs at the kernel level, so it sees and controls the processes, files and network connections an agent actually creates — and can stop them before they execute.

Does AutoSecOps work with our existing tools?

Yes. AutoSecOps connects to tools such as CrowdStrike, Splunk, Sentinel and Palo Alto. If you need them, you can also use our own sensors.

How long does deployment take?

You can connect an existing stack or deploy our sensors in minutes. Timing varies with environment, scope and approval requirements.

What is BreachOps?

BreachOps continuously tests your defenses the way a real adversary would — inside approved scope, with a rollback path — and ships every finding with evidence and a fix.

How much does AutoSecOps cost?

Starter is $8 per device per month, Growth is $12, and Enterprise is custom priced for regulated or air-gapped environments.

Can AutoSecOps and AIDR run air-gapped or on-premises?

Yes. AutoSecOps and AIDR can run in the cloud, in your datacenter, or fully air-gapped. Sensitive data can stay inside your environment.
