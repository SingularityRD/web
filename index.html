01 AI SOC · Triage

Every alert gets a real investigation.

AI analysts pick up each alert the moment it lands, pull context from every connected tool and return a verdict with the evidence attached. Noise closes itself. Real threats reach your team already investigated.

  • Verdicts grounded in your own past analyst decisions
  • Every query, source and step shown — no black box
  • Override any verdict, and the agents learn from it

02 Case management · Investigate

Cases that write themselves.

When an alert matters, AutoSecOps opens a case and does the legwork: the attack story in plain language, a timeline across every tool, the affected users and hosts, and the next best action.

  • What, who, when, where and how — filled in automatically
  • Related alerts grouped into one incident, not twenty tickets
  • Ask the case anything; the copilot answers with sources

03 AI SOAR · Respond

Agents for the unknown. Workflows for the known.

Known threats run through deterministic workflows you can read, test and version. New ones go to agents that reason through them. Anything consequential waits for a person — one click in Slack, Teams or the console.

  • Build visually, or describe the workflow in plain English
  • Approval gates on any step, with role-based rules
  • Every run recorded: inputs, outputs and who approved

04 AIDR · Protect AI agents

AI agent security, enforced in the kernel.

Prompt filters and AI gateways only see what an agent says. AIDR sees what it does — every process, file and network connection, observed at the operating-system kernel, where an agent can’t route around it.

  • Stops prompt injection, tool abuse and data exfiltration before they execute
  • Covers any framework, MCP server or coding agent — no SDK, no code changes
  • Allow, block or ask a human, by policy; every event lands in a case

05 For builders · GitOps & MCP

Click when it’s simple. Code when it matters.

Drive AutoSecOps from your coding agent, keep every workflow and agent prompt in Git, and drop into Python or YAML when a click isn’t enough.

  • MCP server for Claude Code, Codex, Copilot and Cursor
  • Workflows reviewed in pull requests, rolled back in one commit
  • An API and SDK for everything the console can do

Frequently asked questions

How is AutoSecOps different from a traditional SOAR?

A traditional SOAR runs the playbooks you write, and stops when reality doesn’t match them. AutoSecOps runs deterministic workflows for known threats and AI agents that reason through new ones. Risky actions always wait for a person.

What makes AIDR different from a prompt firewall?

A prompt firewall reads text. AIDR also watches what the agent does at the operating-system kernel: the processes it starts, the files it touches and the connections it opens. An agent can be tricked into hiding its intent in a prompt; it can’t hide a system call.

Does it work with our existing tools?

Yes. AutoSecOps connects to 300+ tools, including CrowdStrike, SentinelOne, Microsoft Sentinel, Splunk and Palo Alto. If you don’t have them, our own EDR, NDR and SIEM sensors cover the gap.

How do we stay in control of AI actions?

You decide which actions run automatically, which need approval and who can approve them. Every agent step, query and action is recorded with its evidence, so any decision can be explained after the fact.

Can AutoSecOps run on-premises or air-gapped?

Yes. It runs in the cloud, in your datacenter or fully air-gapped, with the Maximus 1B model running locally. Sensitive data never has to leave your environment.

How much does it cost?

Starter is $8 per device per month and Growth is $12. Enterprise is custom priced for regulated and air-gapped environments.
